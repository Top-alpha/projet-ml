
# Détection des URL malveillantes

## Objectif
Développer un système de Machine Learning capable
de distinguer les URL légitimes des URL malveillantes.
ce fichier explique uniquement les detailles de la partie 1 du projet.

## Structure
- data/ : jeux de données
- notebooks/ : analyses et expérimentations
- src/ : code Python réutilisable
- reports/ : rapports et documentation
- tests/ : vérifications automatiques

## Installation nécessaire
python -m venv .venv
pip install -r requirements.txt

## Ordre de travail
1. Explorer les données
2. Nettoyer et valider les données
